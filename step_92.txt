### How They Coordinate

```
 [Frontend (React + Vite)]
          │  1. User initiates payment (e.g. ₹25,000 to electricity desk)
          │  POST http://localhost:8000/api/payments/analyze
          ▼
 [Backend (FastAPI & Guardian Agent)]
          │  2. Intercepts payment pre-transaction
          │  3. Runs 7 Verification Tools + ML Anomaly + Vector RAG
          │  4. ReAct decision engine scores risk (e.g. Score: 100, Decision: HOLD)
          │  5. Returns structured analysis to Frontend for instant UI display
          │
          │  6. (Asynchronous background task)
          ▼
 [Database (Supabase PostgreSQL)]
             Persists Transaction record (ID, amount, status: HOLD)
             Persists GuardianDecision record (risk score, action, reason)
             Persists RiskEvent & VerificationCheck records
```

### How to Run the Coordinated System

1. **Start the Backend:**
   ```powershell
   cd backend
   python -m uvicorn app.main:app --reload --port 8000
   ```
   *(API docs will be live at `http://localhost:8000/docs`)*

2. **Start the Frontend:**
   ```powershell
   cd frontend
   npm run dev
   ```
   *(UI will be live at `http://localhost:5173` communicating directly with the backend at port 8000)*
